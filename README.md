# FLB Dépannage – site one page statique

## Fichiers
- `index.html`
- `styles.css`
- `script.js`
- `assets/*.svg`
- `robots.txt`
- `sitemap.xml`
- `site.webmanifest`

## À personnaliser avant mise en ligne
1. Remplacer `https://www.votredomaine.fr/` dans :
   - `index.html`
   - `robots.txt`
   - `sitemap.xml`
2. Brancher le formulaire :
   - remplacer `action="#"` dans `index.html` par votre URL Formspree.
3. Vérifier la liste des communes ciblées si vous souhaitez élargir ou resserrer la zone.

## Déploiement
Le site est 100% statique et peut être déployé sur n'importe quel hébergement classique : OVH, o2switch, Netlify, Vercel, GitHub Pages, etc.
